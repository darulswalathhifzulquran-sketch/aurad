Put the Quran text file here as:   quran-uthmani.txt

Download (free):  https://tanzil.net/download/
   Quran Text Type : Uthmani
   Output          : Text (with aya numbers)     <- lines look like  1|1|بِسْمِ ...
Save/rename the file to  quran-uthmani.txt  (UTF-8) and keep it in this folder.

Then, from the project root:
   dart tool/import_quran.dart --dry-run
   dart tool/import_quran.dart

(Folders that start with _ are ignored by tool/import_content.dart.)
