# Al Auradu wal Manaqib (Flutter)

## Run cheyyaan
1. Ee folder VS Code-il open cheyyuka (File > Open Folder).
2. Terminal (Ctrl + `) il:
       flutter create --project-name al_auradu .
       flutter pub get
3. Phone USB debugging on aakki connect cheyyuka (allenkil Android emulator start cheyyuka).
4. flutter run

## Content add cheyyaan
assets/data/library.json il item-kal add/edit cheyyuka.
Categories: "category" field il enthu peru venamenkilum ezhuthaam, app thanne chip aakkum.
